# Handover — 2026-08-13

For Asi. Quick orientation to pick this up cold.

## What this is

`ilanel-poc` — a WordPress + WooCommerce proof-of-concept showing ILANEL's
catalogue and projects could look like [Ross Gardam](https://www.rossgardam.com.au/)
if moved off Squarespace. See the [README](../README.md) for the full pitch
and [ARCHITECTURE.md](ARCHITECTURE.md) for how it's built. This doc is just
"what's the state right now and what's next."

## Run it

One click, no install — boots WordPress + WooCommerce in-browser:

```
https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/aninim/ilanel-poc/master/dist/blueprint.json
```

Nothing persists (it's a demo, not a host). See [INSTALL.md](INSTALL.md) for
a real local install (LocalWP) if you want state that sticks.

## Open right now: missing gallery images on Projects / Light Art pages

Reported today: project pages and Light Art pages render fine structurally,
but not every story row has a photo — some paragraphs show text with a blank
gap where an image should sit.

**Root cause found:** it's a data gap, not a template bug. Both
`themes/ilanel-poc/single-project.php` and `single-light_art.php` correctly
pair each content paragraph with one image from that item's `gallery` array.
But `data/projects.json` has **15 of 51 projects** where `gallery` is shorter
than the paragraph count (mostly capped at exactly 3 images regardless of
paragraph count — 2 projects have zero gallery images at all), and
`data/light-art.json` has **2 of 13** works with the same gap. No script
currently in `scripts/` regenerates these two JSON files, so whatever
produced them originally capped the gallery short of what's on the live
pages.

**In progress:** verifying against the live site (`ilanel.com/projects/<slug>`
and `ilanel.com/light-art/<slug>`) which of these 17 items have more real
photos available to backfill, vs. which gaps are genuine (live page really
has fewer photos than text sections). Once that's back, the fix is a
data-only change to `data/projects.json` / `data/light-art.json` — no
template changes needed.
